About African Recipe Studio

African Recipe Studio is a website created to introduce people to different African dishes. The website provides recipes, ingredients, and simple cooking instructions.

Project Goals

The goal of this project is to create a simple and responsive recipe website using HTML and CSS.

The website also includes interactive features built with CSS, such as recipe category filters and recipe suggestions.

How to Use the Website

Visit the Recipes page to browse the available dishes. Select a recipe to view its ingredients and cooking instructions.

You can also use the Recipe Finder to browse dishes by category or try the Recipe Suggestion feature on the homepage.
